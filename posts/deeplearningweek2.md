# 深度学习入门
这周主要学习了怎么跑代码

第一步：打开运行环境

打开Google Colab (https://colab.research.google.com/)。

上传文件：

点击Upload标签 把文件拖进去 会出现一个长得很像对话框的图案

组成部分

代码块：带有 [ ] 符号的灰色背景区域是代码。

运行按钮：每个代码块左侧有一个“播放”按钮（▶️）。点击它，代码就会运行。

第二步：

随便打开哪一个文件试一试

按顺序运行：从上往下，依次点击每个代码块左边的播放按钮。如果左边出现绿色对勾，说明工具包加载成功。

注意:要开启cpu加速,在菜单栏点击 “代码执行程序 (Runtime)” -> “更改运行时类型 (Change runtime type)” -> 在硬件加速器中选择 “GPU” -> 保存。

第三步：

预测新冠肺炎病例（回归问题）

配置Hyper-parameters：

n_epochs: 训练次数（例如 3000 次）。次数越多，训练越久。

batch_size: 每次塞给模型多少数据。

learning_rate (lr): 学习率。

其实我什么都看不懂 但是就算只用最基础的代码也能跑通baseline

运行 Testing 部分的代码，它会生成一个 pred.csv 文件。

最后把pred文件塞到kaggle上面 发现我的模型在2000个人中排名1950 令人忍俊不禁
