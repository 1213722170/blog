# 我的图片集

把喜欢的 PNG、JPG、WebP、GIF 或 AVIF 图片放在这个文件夹里，网站会自动收录。

也可以在本地网站的「图片」页点击「添加图片」，一次选择多张。先运行 `npm.cmd run write-server`，再运行 `npm.cmd run dev`。

直接放入的图片默认以文件名作为标题。浏览器上传会保留原始文件名作为标题，并按添加时间倒序展示。

metadata.json 由上传服务管理，记录图片标题和添加时间。图片与这个文件一起提交、重新构建部署后，就能在公开网站展示。

删除：在本地图片页点击图片下方的「删除」。误删可点击提示栏的「撤销删除」。删除的原图会暂存在项目根目录 `.gallery-trash/`，不会随网站发布。
